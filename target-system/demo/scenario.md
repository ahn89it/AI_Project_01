## 오늘 발견한 주의사항 (반복 테스트에서 관찰, 코드 수정 안 함)

1. **"정지 상태인 회원 목록" 질문은 시연에서 제외** — 자동 테스트는 10/10 통과했지만,
   생성된 SQL이 자체적으로 `LIMIT 10`을 붙여 실제 21명 중 10명만 보여주면서 "더 있다"는
   안내가 없음. 틀린 답은 아니지만 심사위원 질문에 애매해질 수 있어 확정 질문에서 제외.
2. **Q&A 코드블록 금지 규칙이 50회 중 1회 깨짐** — "반납" 질문 8번째 시도에서 D7이 금지한
   ```java 코드 블록이 재등장하며 실재하지 않는 메서드(`handleOverdue`)를 지어냄. 근거 코드
   expander 자체는 항상 정확하므로, 답변에 코드블록이 뜨면 화제를 근거 expander로 돌릴 것.
3. **콜드스타트 관찰**: 이번 반복 테스트에서는 서버가 이미 웜업된 상태였어서 "첫 응답이
   유독 느림" 현상은 관찰되지 않음(콜드스타트 의심 열이 전부 "-"). 다만 이는 테스트 시작
   전 이미 여러 번 호출한 상태였기 때문 — 시연 당일 완전 콜드 부팅 직후 첫 호출은 여전히
   느릴 수 있으므로 "워밍업 질의 1회" 체크리스트 항목은 유지.
4. **"가장 많이 대출된 책 10권" 질문은 예비로 강등** — 9/10, 1회 실패 시 모델이 요청하지
   않은 "이번 달" 날짜 조건을 스스로 추가해 0건 반환. 본편에서는 사용하지 않고, 심사위원
   추가 질문 대응용으로만 남겨둠.
