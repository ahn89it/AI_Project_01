## 2. 대출·반납

### 대출 가능 여부 확인 — `/loan/checkLoanable.do`
1. **회원 정보 확인**: 회원 ID를 입력받아 회원 데이터베이스에서 해당 회원 정보를 조회합니다.
2. **회원 존재 여부 검증**: 조회된 회원 정보가 없으면 "존재하지 않는 회원입니다."(`MEMBER_NOT_FOUND`)로 거부합니다.
3. **회원 상태 검증**: 회원이 정상 상태가 아니면(예: 연체 중) "연체 중이거나 정상 상태가 아닌 회원입니다."(`OVERDUE_MEMBER`)로 거부합니다.
4. **대출 권수 확인**: 현재 대출 중인 도서 권수를 확인합니다.
5. **대출 권수 제한 검증**: 최대 대출 권수(`LibraryConstants.MAX_LOAN_COUNT`=5)를 초과하면 "최대 대출 권수를 초과했습니다."(`LOAN_LIMIT_EXCEEDED`)로 거부합니다.
6. **대출 가능 확인**: 모든 검증 통과 시 "대출 가능합니다."를 반환합니다.
- 관련 테이블: TB_LOAN, TB_MEMBER

### 도서 대출 등록 — `/loan/insertLoan.do`
1. 회원 상태 확인 — 연체 중인 회원은 대출 거부
2. 대출 한도 확인 — 5권 초과 시 거부
3. 대출 대상 도서 조회
4. 대출 정보 생성 및 등록 (ID 생성, 대출일/만기일 설정, 상태 '대출 완료')
5. 도서 상태를 '대출 중'으로 변경
6. 대출 이력 기록
7. 완료 응답 반환
- 관련 테이블: TB_BOOK, TB_CATEGORY, TB_LOAN, TB_LOAN_HIST, TB_MEMBER

### 대출 상세 조회 — `/loan/selectLoanDetail.do`
대출 ID로 상세 정보를 조회하며, 존재하지 않으면 `DataNotFoundException`이 발생합니다.
- 관련 테이블: TB_BOOK, TB_LOAN, TB_MEMBER

### 대출 목록 조회 — `/loan/selectLoanList.do`
검색 조건에 맞는 데이터를 조회해 반환합니다 (단순 위임).
- 관련 테이블: TB_BOOK, TB_LOAN, TB_MEMBER

### 대출 연장 처리 — `/loan/updateExtend.do`
1. 대출 정보 조회 → 2. 상태가 '대출중'이 아니면 거부(`LoanNotAllowedException`) →
3. 만기일 연장(+7일) → 4. 연장 횟수 +1 → 5. DB 반영 → 6. 연장 이력 기록
- 관련 테이블: TB_BOOK, TB_LOAN, TB_LOAN_HIST, TB_MEMBER

### 도서 반납 처리 — `/loan/updateReturn.do`
1. 대출 정보 확인 (없으면 중단)
2. 반납일/상태 업데이트, 도서를 다시 대출 가능 상태로 변경
3. 연체 확인 — 반납예정일 초과 시 연체 일수 계산, 연체 기록 생성, 회원 상태를 일시 정지로 변경
4. 반납 이력 기록
- 관련 테이블: TB_BOOK, TB_LOAN, TB_LOAN_HIST, TB_MEMBER, TB_OVERDUE

### TB_LOAN — 대출 정보 테이블. 1인 최대 5권까지 동시 대출 가능(LOAN_STATUS=1 건수 기준)

|---|---|
| MEMBER_STATUS | 회원상태. 1=정상, 2=대출정지(연체 제재 중), 9=탈퇴 |
