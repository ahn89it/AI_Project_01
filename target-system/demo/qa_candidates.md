# D7 검증에서 안정적으로 좋은 답이 나온 질문 (D12 시연 후보)

D7 완료 기준 검증 과정에서 실제로 호출해본 5개 질문과 결과 요약. 전부 `POST /api/rag/ask`로
직접 확인함 (2026-08-11).

## 1. "도서 대출은 어떻게 처리되나요?" — 강력 추천
- 회원상태 확인 → 대출권수 확인(5권) → 도서 조회 → 대출 등록 → 도서상태 변경 → 이력기록까지
  전체 흐름을 정확히 설명
- 근거 13건, 전부 실제 코드와 일치
- 응답 42.0초

## 2. "책을 반납하면 시스템에서 무슨 일이 일어나나요?" — 추천
- 반납 처리 + 연체 시 TB_OVERDUE 생성 + 회원 대출정지 처리까지 정확히 설명
- 응답 17.8초 (5개 중 가장 빠름)

## 3. "연체된 회원은 책을 빌릴 수 있나요?" — 추천 (단, 상세설명에 지어낸 코드 조각이 섞일 수 있음)
- 결론("불가")은 항상 정확하고, `LoanServiceImpl.checkLoanable` 근거 인용도 정확함
- 다만 EXAONE이 "상세 설명"에서 실제 코드를 다시 타이핑하며 `MemberStatus.OVERDUE`처럼
  존재하지 않는 이름을 지어내는 경우가 관찰됨 (references API 필드 자체는 항상 정확 —
  LLM 출력에서 파싱하지 않고 context_builder가 실제로 쓴 코드 기준으로 만들기 때문)
- 시연 때는 "3) 근거" 목록 위주로 보여주는 편이 안전

## 4. "회원은 몇 권까지 빌릴 수 있나요?" — 강력 추천
- "최대 5권"까지 정확히 답함 (LibraryConstants.MAX_LOAN_COUNT 값까지 컨텍스트에 포함시킨
  덕분 — D7 작업 중 발견한 빈틈을 보강한 결과)
- 응답 15.5초 (가장 빠르고 가장 정확)

## 5. "도서 예약 기능은 어떻게 되나요?" (할루시네이션 테스트용)
- 실제로 없는 기능 → "제공된 코드에서는 도서 예약 기능에 대한 직접적인 구현 내용은
  명시적으로 확인되지 않습니다"로 정직하게 답함, 없는 기능을 지어내지 않음
- 발표 자료 "신뢰성" 페이지 재료로 사용 가능
