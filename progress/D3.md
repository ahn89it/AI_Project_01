# D3 (2026-08-11) — 시딩 보완 + 시연용 버그 자료

사용자가 D3 프롬프트를 제공했으나, 상당 부분이 D2에서 이미 처리되어 있어 **중복된 부분은 skip하고
빠진 부분만 추가**하는 방식으로 진행.

## D2에서 이미 완료되어 pass한 항목
- 의도적 버그 2개 삽입 (`LoanServiceImpl.insertLoan()`): 회원 NULL 체크 누락(NPE), 도서 대출가능여부
  검증 누락(중복대출) — D3 프롬프트가 요구한 위치·형태와 동일. "// 버그" 같은 표식 주석 없음(확인함)
- `db/seed.sql` 자체 (FK 정합성, "이번 달" 연체 데이터 포함)는 이미 존재

## 이번에 새로 진행한 작업

### 1. 읽기전용 DB 계정
- `db/seed.sql`에 `ai_reader` 계정 생성 SQL 추가 (`GRANT SELECT ON library_db.*`)
- 실제 접속 검증: SELECT 성공 / INSERT는 `ERROR 1142 command denied`로 정상 차단 확인

### 2. BUGS.md
- `target-system/BUGS.md` 신규 작성. 버그별 위치(파일:라인), 원인 코드, 재현 방법, 기대 동작 기록
- analyzer 인덱싱 시 제외해야 함을 명시 (analyzer 착수 시점에 인덱서 제외 목록에 반영 필요 — 아직
  analyzer 자체가 없으므로 지금은 문서화만)

### 3. 시연용 에러 로그 (demo/error_log_1.txt)
- 실제 재현으로 진짜 스택트레이스를 확보하는 방식 채택: 리플렉션으로 `LoanServiceImpl`을 직접
  인스턴스화하고 `MemberMapper`를 null 반환 스텁으로 주입 → `insertLoan()` 호출 → 실제 NPE 발생시킴
  (Tomcat/서버 기동 없이도 검증 가능한 방법)
- 실제 얻은 스택트레이스: `LoanServiceImpl.java:63`, 호출부 `LoanController.java:54` — 둘 다
  현재 소스 라인과 정확히 일치 (파일을 직접 읽어 재확인)
- 이 실제 프레임을 Tomcat 9 + Spring 5.3 MVC 디스패치 체인(DispatcherServlet → HandlerAdapter →
  InvocableHandlerMethod → 리플렉션 호출) 안에 끼워 넣어 운영 환경에서 실제로 나올 법한 전체
  스택트레이스로 구성. 프레임워크 내부 라인번호는 실제 값이 아닌 통상적인 값(우리 코드 라인만
  정확하면 되므로)
- 실제로는 `GlobalExceptionHandler`(@ExceptionHandler(Exception.class))가 이 예외를 잡아
  ERROR 레벨로 로깅하므로, 로그 형식도 그에 맞춰 SLF4J/Logback 출력 형태로 작성
- `logback.xml` 패턴에 날짜(`yyyy-MM-dd`)가 빠져있던 것을 이번에 보완 (기존엔 시:분:초만 있었음)

**수치가 다름**. 다만:
- FK 정합성, "이번 달 연체 15건 이상" 등 실질적 요구사항은 이미 충족(20건)

  BUGS.md, 에러로그)만 보완하는 쪽을 선택
